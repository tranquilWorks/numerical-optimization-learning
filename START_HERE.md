# Start here

This is the Numerical Methods and Optimization interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the reference slice; runnable modules are the contiguous `implemented`
prefix in `curriculum/modules.json`, and later modules map one-to-one to governed Portfolio Control
batches. A learner session follows read → visualize → move one lever → visualize the change →
read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
