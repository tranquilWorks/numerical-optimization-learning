## Governing numerical inventory

The fixed lesson model uses orthonormal strong and weak source directions:

```text
q_strong = [1; 1] / sqrt(2)
q_weak   = [1;-1] / sqrt(2)
A = q_strong*q_strong' + (1/kappa)*q_weak*q_weak'
```

The true source is the unit strong direction, so the exact measurement also has unit norm. For this
normalized baseline only, a relative measurement perturbation of magnitude `eta` and angle `theta`
from strong toward weak gives

```text
relative source error = eta * sqrt(cos(theta)^2 + kappa^2*sin(theta)^2)
directional amplification = sqrt(cos(theta)^2 + kappa^2*sin(theta)^2)
sensor-row separation = 2*atan(1/kappa)
```

The retained cases are:

- baseline: `kappa=100`, `eta=0.001`, `theta=90 degrees`; 0.1% input error, 10%
  source error, 100-fold amplification, and row separation `2*atan(0.01)` degrees;
- conditioning sweep: `kappa=[1,3,10,30,100,300,1000]`, with `eta=0.001` and
  `theta=90 degrees` fixed; source error grows while row separation shrinks;
- direction sweep: `theta=[0,15,30,45,60,75,90]` degrees, with `kappa=100` and
  `eta=0.001` fixed; realized amplification spans one through 100;
- well-conditioned limit: `kappa=1` makes `A` the identity and every direction has unit gain;
- zero-error limit: the source stays unchanged while geometric directional amplification remains
  defined;
- strong-direction limit: amplification stays one even when `kappa=10^6`;
- broken residual case: `kappa=10^6`, one ppm, and `theta=90 degrees` create approximately
  100% source error while the perturbed-data residual remains near machine precision;
- maximum supported case: `kappa=10^6`, one-percent error, and fixed 2-by-2 outputs remain finite
  in the retained source contract.

The model accepts `kappa` in `[1,10^6]`, error angle in `[-90,90]` degrees, and either zero
relative error or a nonzero error in `[10^-6,0.01]`. The one-ppm floor is lesson resolution, not a
binary64 spacing claim. The UI narrows direction to `[0,90]`, exposes `log10(kappa)` in `[0,6]`,
and exposes integer measurement-error ppm in `[0,10000]`.
